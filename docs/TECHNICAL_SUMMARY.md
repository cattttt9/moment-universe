# 技术总结

> 本文档随真实开发过程持续更新。未验证的能力不会写成已完成。

## 1. 项目背景

《此刻宇宙》希望把用户主动留下的一句话和三个自定义状态参数转换成数字艺术作品，
同时避免将文字包装成心理测试或上传到服务端。

## 2. 最初需求

首版需要覆盖输入、参数、文字粒子转场、Three.js 动态星云、互动、Canvas 海报、本地保存、
响应式与 GitHub Pages 发布，并以 lint、test、build 作为发布门槛。

与渲染蓝图 → Three.js 场景 / 海报 / 本地档案。

## 12. 遇到的真实问题

- 初始工作目录为空且不是 Git 仓库，需要从零建立可维护工程。
- 通用网站初始化能力与“Vite、禁止 Next.js”的明确架构要求冲突，因此未使用该初始化器。

## 13. 问题定位过程

通过目录列表、Git 根目录检测、Node 与 npm 版本检查确认初始环境。

## 14. 采用的解决方案

## 15. 放弃过的方案及原因

- Vinext/通用托管初始化：与纯 Vite、GitHub Pages 的目标冲突。

## 16. AI 辅助开发中有效的做法

当前仅记录：先建立验收命令与文档台账，再进入视觉功能，避免末期集中补文档。
