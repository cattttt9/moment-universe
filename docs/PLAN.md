# 开发计划

## 项目目标

完成一个无需后端、隐私友好、可在 GitHub Pages 发布的互动艺术网页，将用户输入与
三个自主参数转化为确定性动态星云，并支持导出个人宇宙档案。

## MVP 范围

- [ ] 六阶段完整体验
- [ ] 1–80 字本地输入
- [ ] 能量、秩序、波动控制
- [ ] 确定性哈希、随机数与宇宙生成
- [ ] Three.js 动态星云
- [ ] 文字粒子坍缩转场
- [ ] 鼠标、触摸、键盘核心交互
- [ ] 3:4 Canvas PNG 海报
- [ ] 最近 20 条本地档案与恢复
- [ ] GitHub Pages 自动部署
- [ ] 响应式、减少动态与性能降级

## 非 MVP 范围

- 账号、云端数据库和社区
- AI 情绪分析、诊断或价值判断
- 评论、点赞、实时多人互动
- 付费、NFT 或依赖密钥的第三方服务

## 技术方案

- Vite + React + TypeScript 组织纯前端应用
- Three.js 使用单一渲染循环和可释放资源
- GSAP 编排界面与生成转场
- 离屏 Canvas 采样文本像素，Canvas 2D 合成海报
- 哈希与固定种子 PRNG 集中在 `src/engine`
- localStorage 保存版本化、可校验的最近档案

- [ ] 阶段四：Three.js 星云
- [ ] 阶段五：文字粒子转场

- [ ] 阶段八：发布前收尾

## 验收标准

- `npm run lint`、`npm run test`、`npm run typecheck`、`npm run build` 全部通过
- 相同文字与参数生成一致的配置和几何数据
- 桌面与手机竖屏均可完成输入、生成、互动和导出
- 降低动态时跳过高强度转场，低质量等级减少粒子与像素比
- 页面隐藏与组件卸载时暂停或释放渲染资源
- 不产生用户输入的远程网络请求

## 风险与方案

| 风险 | 处理方案 |
| --- | --- |
| 中文字体轮廓几何成本高 | 离屏 Canvas 像素采样，不依赖字体网格解析 |
| 移动端 GPU 性能差异大 | 三档质量等级、限制像素比和粒子数 |
| WebGL 上下文不可用 | 结果页提供静态 Canvas 降级说明与继续导出入口 |
| 海报跨字体平台差异 | 使用系统中文字体栈、等待字体就绪并提供错误重试 |
| 本地档案结构升级 | 存储版本号、运行时字段校验和安全回退 |
| GitHub Pages 子路径 | 由环境变量和仓库名动态设置 Vite `base` |
