# 开发进度

## 2026-07-25 · 沉浸式视觉引擎重构启动

### 开始前审计

- Git 工作区干净，原分支为 `feature/moment-universe`，最近提交为 `e211107`
- 创建本地分支 `fix/immersive-universe-engine`；本轮只做本地提交，不推送远程
- 当前 WebGL 只在结果页挂载，前四个阶段仍使用独立的 CSS 星尘，无法形成连续空间
- 结果场景只有一个旋臂粒子公式、单星核和暖褐色系，参数主要改变速度、扰动和亮度
- 结果主体固定偏右且尺度较小，镜头只有滚轮距离变化，没有分阶段镜头或多层视差
- `OrbitControl` 使用覆盖整个圆盘的透明原生 `range`，原生控件接管指针命中；圆周拖动逻辑
  缺少显式拖动态、释放、连续角度处理和 RAF 节流
- 被旋转的是空的 `.orbit` 元素，小天体 `.planet` 是其兄弟节点，因而不会随角度移动

### 当前状态

已有页面流程、视觉语言、确定性基础、海报和本地存储均保留。重构将从可测试的
`OrbitDial` 和视觉配置模型开始，再把 WebGL 扩展为全流程共享舞台。

### 下一步

- 实现可拖动、可触摸、可键盘操作的 `OrbitDial`
- 建立八种确定性宇宙原型和八套克制色板
- 建立单 renderer、单 RAF 的共享 `UniverseStage`
